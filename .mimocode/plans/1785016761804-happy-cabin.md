# Plan: Ekran podsumowania bitwy z zbieraniem łupów

## Context

Po bitwie w grze Legion wszystkie przedmioty z ziemi (GLEBA) są natychmiast kasowane (linia 146-152 w `LegionMainAction.cs`). Nie ma żadnego ekranu podsumowania bitwy — gracz nie wie, co zabrał, ile doświadczenia zdobył, ani jakie łupy zostały rzucone przez pokonanych wrogów. Chcemy dodać ekran podsumowania, który pozwala graczowi zebrać łupy (kamienie, oszczepy, broń) z pola bitwy przed powrotem do mapy świata.

## Podejście

Dodajemy nową metodę `PODSUMOWANIE_BITWY()` w `LegionMainAction.cs`, wywoływaną **przed** kasowaniem GLEBA w sekcji `Exit2:`. Ekran wyświetla:
- Wynik bitwy (zwycięstwo/porażka)
- Listę żyjących wojowników obu stron
- Siatkę łupów z ziemi (GLEBA) z możliwością zabrania wybranych przedmiotów
- Podsumowanie: ile sztuk złota zostało zebranych (automatycznie z martwych wrogów)

## Szczegóły implementacji

### 1. Nowa metoda `PODSUMOWANIE_BITWY()` w `LegionMainAction.cs`

Dodajemy po istniejącej metodzie `ZABIJ()` (około linii 3273). Metoda:

1. **Zbiera łupy z GLEBA do tymczasowej listy** — skanuje wszystkie 111 sektorów GLEBA, zbiera nie-puste przedmioty do listy `List<int> lupItems`
2. **Wyświetla ekran OKNO** na screenie 1 (tak jak STATUS/OPCJE)
3. **Pokazuje:**
   - Tytuł: "Podsumowanie bitwy" + wynik (zwycięstwo/porażka)
   - Żywych wojowników: "Nasi: X/10, Wróg: Y/10"
   - Siatkę łupów (maks 16-20 przedmiotów) z ikonami bobów i nazwami z `BRON_S[]`
   - Przycisk "Zabierz wszystko" i "Dalej"
4. **Interakcja:** Kliknięcie na przedmiot zabiera go do plecaka wybranego wojownika (lub automatycznie do najlepszego dostępnego slotu). Ctrl+click = auto-zabierz.
5. **Po zamknięciu:** kasuje GLEBA i kontynuuje istniejący flow

### 2. Modyfikacja `Exit2:` w `MAIN_ACTION()` (linie 134-200)

```csharp
Exit2:;
    // --- NOWE: przed kasowaniem GLEBA ---
    PODSUMOWANIE_BITWY();
    // --- KONIEC NOWEGO ---
    
    // Istniejący kod: fade out, kasowanie GLEBA, statystyki...
    screens.Screen(0);
    screens.Fade(2);
    // ... reszta bez zmian
```

### 3. Logika ekranu podsumowania

Wzorujemy się na istniejących wzorcach UI:
- `OKNO(80, 60, 320, 200)` — okno w centrum ekranu
- `GADGET()` do rysowania przycisków i paneli
- `screens.Text()` do wypisywania tekstu
- `screens.PasteBob()` do ikon przedmiotów (boby z `BRON[BR, B_BOB]`)
- Zones do klikania na przedmioty

Schemat layoutu:
```
+------------------------------------------+
| Podsumowanie bitwy                        |
| Wynik: Zwycięstwo!                       |
| Nasi: 8/10    Wróg: 0/10                 |
|                                           |
| Łupy z pola bitwy:                       |
| [ikona] Miecz (-5 dmg)    [ikona] Oszczep|
| [ikona] Głaz (-10 dmg)    [ikona] Łuk    |
| ...                                      |
|                                           |
| Zabrano: 0 przedmiotów                   |
|                      [Zabierz wszystko]  |
|                              [Dalej]      |
+------------------------------------------+
```

### 4. Zabieranie przedmiotów

Dla każdego klikniętego przedmiotu:
1. Sprawdź, czy jest miejsce w plecaku któregokolwiek żywego wojownika (`TPLECAK` do `TPLECAK+7`)
2. Jeśli tak — dodaj przedmiot, usuń z listy łupów
3. Jeśli nie — wyświetl komunikat "Brak miejsca!"
4. "Zabierz wszystko" iteruje po wszystkich łupach i próbuje dodać do plecaków kolejnych wojowników

## Weryfikacja

1. Uruchom grę, rozpocznij bitwę z wrogami
2. Zabij kilku wrogów — powinni rzucać przedmioty (kamyki, oszczepy, broń)
3. Zakończ bitwę przyciskiem "Koniec Akcji"
4. Powinien pojawić się ekran podsumowania z listą łupów
5. Kliknij na przedmioty, aby je zabrać — sprawdź w WYBOR(inventory) czy trafiły do plecaka
6. Kliknij "Dalej" — ekran się zamknie, gra wróci do mapy świata
7. Sprawdź, że GLEBA jest poprawnie kasowane po opuszczeniu ekranu
